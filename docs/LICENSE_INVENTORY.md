## Release check

Before publishing a source release or result bundle:

1. Confirm that every distributed file appears above or carries its own notice.
2. Recheck dependency and evaluated-model licenses at the exact pinned versions.
3. Keep `LICENSE`, `NOTICE`, `SCENARIO_LICENSE.md`, and required third-party
   notices with the distribution.
4. Remove secrets, personal data, private cases, local absolute paths, and
   unlicensed model artifacts.
5. Identify the license of generated results explicitly; do not imply that the
   repository licenses grant rights the operator does not hold.
6. Record source revision, dirty-tree state, suite hash, model digest, runtime,
   prompt/configuration hashes, and the research-status disclaimer.
