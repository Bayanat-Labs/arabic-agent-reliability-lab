# No held-out scenarios are distributed in v0

Version 0 contains no official held-out scenario pack and supports no held-out
score claim. This empty directory makes that boundary explicit.

If Bayanat Labs introduces an official held-out evaluation in a future release,
its active prompts, fixtures, assertions, and traces will live outside the public
repository. The release will define evaluator access, result publication, and
retirement rules before any score is described as held out. Retired cases may be
published only after replacement and an explicit license review.

The CC BY 4.0 grant in `SCENARIO_LICENSE.md` does not apply to this placeholder
or to future non-public material merely because it follows the same directory
convention.
